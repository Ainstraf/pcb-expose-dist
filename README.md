# pcb-expose

Засветка **фоторезиста на печатных платах** через LCD фотополимерного принтера **Anycubic Photon Mono 4**.

Берёте папку Gerber из **Altium** (OutJob), собираете маску под матрицу принтера и сохраняете `.pm4n`. Файл кладёте на флешку — и экспонируете плату, как обычную «печать», только без смолы: нужен UV для резиста.

**English:** [README.en.md](README.en.md)

> Сейчас это ранний публичный релиз. Сборка уже гонялась на живом Mono 4, но процесс ещё живой: возможны баги и изменения. Исходники в этом репозитории **не лежат** — здесь Windows-сборка и документация для тех, кто хочет просто пользоваться.

## Кому это

- Делаете платы дома / в мастерской и уже есть (или планируется) Photon Mono 4  
- Ведете проект в Altium и хотите уйти от плёнок / «на глазок» к нормальной засветке по Gerber  
- Нужен понятный путь: Gerber → маска → файл для принтера  

Другие модели Photon / иные слайсеры **не обещаем**. Заточка под Mono 4 (LCD 9024×5120, шаг ~17 µm).

## Скачать

Актуальная сборка: **[Releases](https://github.com/Ainstraf/pcb-expose-dist/releases)** → `pcb-expose-windows-x64.zip`

1. Распаковать архив  
2. Запустить `pcb-expose\pcb-expose.exe`  
3. Нужна **вся папка** целиком (рядом с exe лежит `_internal`). Один файл exe отдельно не заведётся  

Windows x64. Установщик не нужен.

## Как пользоваться

1. Открыть папку Gerber (OutJob Altium) или перетащить её в окно программы.  
2. Включить нужные слои; при необходимости — invert, зеркало, сдвиг (offset).  
3. Включить режим **«Как на LCD»** — так вы видите и экспортируете то, что реально уйдёт на матрицу.  
4. При желании подкрутить качество растра и/или прогнать **тест экспозиции** (несколько зон с разным временем — удобно подобрать дозу под ваш резист и зазор).  
5. **Экспорт .pm4n**.  
6. Скопировать файл в **корень** флешки **FAT32**, имя **латиницей**, вставить в принтер и запустить как обычный job.

На принтере это выглядит как обычный файл в списке. Превью тоже своё — не чужой квадрат из шаблона.

### На что обратить внимание

- Для экспорта ориентируйтесь на **«Как на LCD»**, а не на быстрый обзорный превью-режим.  
- Плата должна помещаться в рабочую (safe) зону оснастки; иначе будет предупреждение — двигайте offset или уменьшайте заготовку.  
- Тест экспозиции — про подбор времени засветки, а не про «сразу готовую плату в серию».  
- Травление — отдельная история. Для проверки засветки часто достаточно проявить резист и посмотреть рисунок.
