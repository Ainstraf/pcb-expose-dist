# pcb-expose

> **В разработке** — ранний релиз для проверки на железе. Возможны ошибки и изменения.

Утилита для **экспонирования фоторезиста на печатных платах** с помощью фотополимерного принтера **Anycubic Photon Mono 4**.  
Принимает Gerber из **Altium** (папка OutJob) и сохраняет `.pm4n` для печати/засветки на принтере.

Только Mono 4.

English: [README.en.md](README.en.md)

## Скачать

[Releases](https://github.com/Ainstraf/pcb-expose-dist/releases) → `pcb-expose-windows-x64.zip`

## Как пользоваться

1. Распаковать zip.
2. Запустить `pcb-expose\pcb-expose.exe` (**нужна вся папка**, не один exe).
3. Открыть папку Gerber (OutJob Altium) или перетащить её в окно.
4. Выбрать слои, при необходимости invert / зеркало / offset.
5. Включить **«Как на LCD»** → при необходимости настроить качество растра и тест засветки → **Экспорт .pm4n**.
6. Скопировать файл в **корень** флешки FAT32, имя **латиницей**, вставить в принтер.

Опционально: калибровочный тест экспозиции (несколько вариантов вывода под разные сценарии работы).
